==================================================
1. POST /api/v1/auth/logout
==================================================

Create the protected logout endpoint.

Requirements:

- POST /api/v1/auth/logout
- Must use PlatformAuthGuard.
- Must NOT be @Public().
- Read sessionId ONLY from:
  request.authenticatedPlatformUser.sessionId
- Never accept sessionId from request body, query, or params.

Behavior:

- Revoke ONLY the current authenticated session.
- Use the existing PlatformSessionService.revokeOne foundation.
- revokedBy = authenticated platform user id.
- revocationReason = USER_LOGOUT.
- Clear the refresh-token cookie.
- Operation must be idempotent.

Do NOT:
- delete the session.
- delete refresh-token history.
- blacklist the access token.
- modify tokenVersion.
- revoke other sessions.
- return a refresh token.
- return an access token.

The existing access token may remain cryptographically valid until its normal expiration.

==================================================
2. POST /api/v1/auth/logout-all
==================================================

Create the protected logout-all endpoint.

Requirements:

- POST /api/v1/auth/logout-all
- Must use PlatformAuthGuard.
- Must NOT be @Public().
- Read userId ONLY from:
  request.authenticatedPlatformUser.userId
- Never accept userId from request body, query, or params.

Behavior:

- Revoke ALL ACTIVE sessions belonging to the authenticated user.
- Use the existing PlatformSessionService.revokeAll foundation.
- revocationReason = USER_LOGOUT_ALL.
- Clear the refresh-token cookie.
- Operation must be idempotent.

Do NOT:
- modify tokenVersion.
- delete sessions.
- delete refresh-token history.
- affect another user's sessions.
- return access or refresh tokens.
