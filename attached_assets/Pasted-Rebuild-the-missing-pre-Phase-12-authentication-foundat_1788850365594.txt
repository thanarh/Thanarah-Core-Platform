3. PlatformAuthGuard

- @Public() routes bypass authentication.
- Missing Authorization header → AUTH_TOKEN_MISSING.

- Session user mismatch → AUTH_SESSION_USER_MISMATCH.
- REVOKED/COMPROMISED/EXPIRED session → corresponding authentication failure.
- Attach only safe authenticated context to the request.

- tokenFamilyId does not change.
- Replace refreshTokenHash.

- Compare against current session token hash.
- If current hash does not match, check refresh-token history.
- If the token exists in history, mark the session COMPROMISED and set reuseDetectedAt.
