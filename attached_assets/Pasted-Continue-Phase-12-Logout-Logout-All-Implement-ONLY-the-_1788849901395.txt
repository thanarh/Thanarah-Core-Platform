Continue Phase 12 — Logout + Logout-All.

Implement ONLY the following authentication endpoints. Do not start any later phase.

1. POST /api/v1/auth/logout
- Protected by PlatformAuthGuard.
- Read sessionId ONLY from request.authenticatedPlatformUser.sessionId.
- Revoke ONLY the current authenticated session.
- Use PlatformSessionService.revokeOne.
- revokedBy = authenticated platform user id.
- revocationReason = USER_LOGOUT.
- Clear the refresh-token cookie.
- Must be idempotent.
- Do not delete the session or refresh-token history.
- Do not blacklist the access token. It may remain cryptographically valid until expiry.
- Do not accept sessionId from the request body.

2. POST /api/v1/auth/logout-all
- Protected by PlatformAuthGuard.
- Read userId ONLY from request.authenticatedPlatformUser.userId.
- Revoke ALL ACTIVE sessions for that user using the existing revokeAll functionality.
- revocationReason = USER_LOGOUT_ALL.
- Clear the refresh-token cookie.
- Do NOT modify tokenVersion.
- Do not delete sessions or refresh-token history.
- Do not accept userId from the request body.
