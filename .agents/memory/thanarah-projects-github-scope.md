name: نطاق المشاريع وGitHub
description: محاور المرحلة السادسة وشرط دورة التغيير التجريبية بين العميل وCTO.
---

حدد المستخدم المرحلة السادسة: مشروع مستقل لكل عميل عند الحاجة؛
مستودعات خاصة وقوالب؛ إدارة الإصدارات ومراجعة التغييرات؛ سجل
Deployments وLogs؛ موافقات النشر وRollback؛ ربط المشروع بلوحة
العميل ولوحة CTO.

**Why:** شرط الإغلاق بالنص هو «تعديل تجريبي ينتقل من الطلب إلى الاختبار
ثم النشر والتوثيق».

**How to apply:** لا تعتبر تسجيل مشروع أو ربط مستودع أو إنشاء شاشات
دليل إغلاق المرحلة. أثبت دورة التغيير الحقيقية على مشروع تجريبي
وبموافقات واضحة، ولا تنشئ مشروعًا مستقلًا لكل عميل افتراضيًا لأن
المستخدم قيده بعبارة «عند الحاجة». تفاصيل القبول في
`docs/PHASE_06_PROJECTS_GITHUB_ACCEPTANCE.md`.
