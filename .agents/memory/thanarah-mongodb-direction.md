---
name: Thanarah MongoDB-only direction
description: The user's explicit database decision superseding the earlier hybrid architecture.
---

اعتماد MongoDB ‏(NoSQL) للمنصة بالكامل، بما فيها الحسابات والجلسات والصلاحيات والاشتراكات وبيانات العيادات؛ لا اعتماد على SQL في التشغيل المستهدف.

**Why:** صحح المستخدم طلب إعداد MySQL ثم أكد صراحةً: «نعم، MongoDB للمنصة بالكامل». هذا القرار يلغي قرار المعمارية الهجينة السابق.

**How to apply:** لا تطلب اتصال MySQL لإكمال إعداد المنتج، ولا تعتبر الاعتماد الحالي عليه متطلبًا دائمًا. أكمل تحويل التخزين المركزي واختبارات قبوله إلى MongoDB مع الحفاظ على العزل والأمان والبيانات. هذا القرار لا يجيز حذف بيانات أو نقل بيانات إنتاج أو النشر دون موافقة منفصلة.

أكد المستخدم أن اتصال MongoDB المحفوظ مخصص للتطوير أو الاختبار، وليس للإنتاج.

**Why:** أجاب المستخدم «نعم، تطوير أو اختبار» عند سؤاله عن غرض الاتصال قبل ربط التطبيق.

**How to apply:** يمكن التحقق من الاتصال التطويري ضمن العمل المعتمد؛ لا تستنتج من ذلك تصريحًا للوصول إلى الإنتاج أو حذف بيانات الاختبار القائمة.
