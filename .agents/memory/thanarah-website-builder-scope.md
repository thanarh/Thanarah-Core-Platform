حدد المستخدم ستة محاور للمرحلة الخامسة: مكتبة القوالب؛ محرر السحب
والإفلات؛ صفحات الأطباء والخدمات؛ تخصيص الهوية والنطاق؛ الحجز المرتبط
بـSmart Clinic؛ المعاينة والنشر واسترجاع الإصدارات.

**Why:** شرط الإغلاق بالنص هو «إنشاء موقع عيادة كامل ونشره على نطاق تجريبي».

**How to apply:** لا تعتبر محررًا أو معاينة داخل التطوير وحدهما إغلاقًا
للمرحلة. يجب إثبات الموقع المنشور والحجز المرتبط بالعيادة واسترجاع
نسخة الموقع دون استرجاع بيانات المرضى أو حذف الحجوزات. تفاصيل القبول
في `docs/PHASE_05_WEBSITE_BUILDER_ACCEPTANCE.md`.
